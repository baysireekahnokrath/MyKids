# Mockup ก่อนเสมอ (ผู้ใช้สั่งให้จำถาวร)

## ขั้นตอน

1. **คุยขอบเขตก่อน**: ใครใช้, เนื้อหามาจากไหน, ความเป็นส่วนตัว, ฟีเจอร์ v1
   (ถามด้วย AskUserQuestion ไม่เกิน 4 ข้อ)
2. **ทำ mockup บน Design canvas** (Artifact → quickstart intent `design` → สร้างจาก Design type)
   - 1 artboard ต่อ 1 หน้าจอ, ขนาดมือถือ 390×844, เชื่อมหน้าด้วยลิงก์ และกดเล่นได้ (`is_interactive`)
   - ใช้ข้อมูลจริงที่มีอยู่ (ตารางสอบจาก CLAUDE.md) ส่วนเนื้อหาที่ยังไม่มีเอกสาร ให้ติดป้าย "ตัวอย่าง"
   - สีของลูก: Beiya แดง #D64545 · Beana เขียว #2E9E5B · Bene เหลือง #F2C230 (ถ้าเป็นตัวหนังสือบนสีเหลือง ใช้สีเข้ม)
   - ฟอนต์ Mitr (หัวข้อ) + IBM Plex Sans Thai (เนื้อหา), ปุ่มสูง ≥44px ให้เด็กกดง่าย ห้ามใช้ emoji เป็นไอคอน
3. **ส่งลิงก์ให้ผู้ใช้ดู แล้วรอคำติชม/อนุมัติ** แก้ mockup ตามที่สั่งจนกว่าจะพอใจ
4. **หลังอนุมัติเท่านั้น** ค่อยเริ่มเขียนโค้ดจริง และยังต้องถามก่อน deploy ขึ้น Vercel ทุกครั้ง
