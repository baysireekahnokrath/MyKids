# ลงปฏิทินกำหนดการของลูกๆ

## ขั้นตอน

1. **ตรวจวันที่**: ถ้าวันที่กับวันในสัปดาห์ที่ผู้ใช้ให้มาไม่ตรงกัน → ถามก่อน ห้ามเดาเอง
2. **ตรวจรายการซ้ำ**: ใช้ `list_events` ในปฏิทิน `arthitbay@gmail.com` ช่วงวันที่นั้น
   ตรวจทั้งวันที่และชื่อ และดูด้วยว่ารายการหลายวันถูกลงเป็นช่วงเดียวไว้แล้วหรือยัง → ถ้ามีแล้ว ห้ามลงซ้ำ
3. **สร้าง event เต็มวัน** ในปฏิทินหลัก (ไม่ใช้ปฏิทิน Family)
   - ชื่อ: `<สี> [<ชื่อลูก>] <เรื่อง>` — 🔴 Beiya · 🟢 Beana · 🟡 Bene · ทั้ง 3 คนใช้ 🔴🟢🟡 [เด็กๆ]
   - รายการหลายวันให้ลงเป็น event เดียว (end = วันถัดจากวันสุดท้าย)
   - ใส่เนื้อหาที่ออกสอบ/หน้า/ชุดเอกสารไว้ใน description
4. **ใส่การแจ้งเตือน popup ทุกครั้ง** ผ่าน `overrideReminders` (นับเป็นนาทีก่อน 00:00 ของวัน event)
   | ประเภท | นาที |
   |---|---|
   | สอบ, บันทึกการอ่าน, ข่าววิทยาศาสตร์ | 10980, 5220, 360 |
   | อาขยาน | 21060, 10980, 5220, 360 |
   | ค่าเทอม | 5220, 360 |
   | ส่งสมุด, ชมโขน | 1800, 360 |
   | เขียนไทยแต่ละครั้ง | 360 |
   (10980 = 7 วันก่อน 09:00 · 5220 = 3 วันก่อน 09:00 · 1800 = 2 วันก่อน 18:00 · 360 = คืนก่อน 18:00 · 21060 = 14 วันก่อน 09:00)
5. **อัปเดต CLAUDE.md** ส่วนกำหนดการของลูกคนนั้น แล้ว commit
6. ถ้าเห็นว่าพี่น้องสอบวันชนกัน ให้แจ้งผู้ใช้ด้วย
