# ธีม MyKids: พาสเทลสติกเกอร์

ที่มา: แอปจริงที่ session "ตารางเวลา และ บทเรียนต่างๆ" สร้างไว้ (branch `claude/inspiring-noether-tkvklk`
ไฟล์ `public/js/theme.js` และ `public/css/style.css`) ถ้าไฟล์นั้นเปลี่ยน ให้ยึดตามไฟล์

## ค่าพื้นฐาน

- พื้นหลัง: ครีม `#FFF8EC` (หน้าของลูกใช้สี `soft` ของธีมที่เลือก) · การ์ด/ปุ่ม: ขาว `#FFFFFF`
- ตัวหนังสือ (หมึก): `#2B2552` · ตัวรอง: `#6A6585` · ถูก: `#17603C` บน `#D8F3E3` · ผิด: `#A3281D` บน `#FFE0DC`
- ฟอนต์: หัวข้อใช้ **Kanit** 600/800 · เนื้อหาใช้ **Noto Sans Thai Looped** 400/600/700
- ป้ายนับถอยหลังเป็นแคปซูล (radius 999px) ถ้าใกล้สอบใช้สี `c2`
- ลายพื้นหลังจางๆ (opacity ~0.4): ดอกไม้หน้ายิ้ม ดาว ประกาย หัวใจ เส้นหยัก จุด
- รูปตัวแทนของลูกเป็นดอกไม้ 8 กลีบหน้ายิ้ม ใช้สี `main` และกลางดอกเป็นสี `c2`

## สไตล์ (ลูกเลือกเองได้)

| id | ชื่อ | radius | ขอบ | เงา |
|---|---|---|---|---|
| flower | ดอกไม้ยิ้ม | 28px | 3px หมึก | `5px 5px 0 #2B2552` |
| blob | บล็อบยิ้ม | 40px | ไม่มี | `0 7px 0 rgba(43,37,82,.16), 0 16px 28px rgba(43,37,82,.10)` |
| doodle | ดูเดิลสติกเกอร์ | 18px | 3px หมึก | `4px 4px 0 #2B2552` |

## สีพาสเทล 6 ชุด (main / soft / deep / c2 / c3)

- lavender ลาเวนเดอร์: #BDAEE6 / #EDE7FA / #5B3FA0 / #FFE27A / #F4B6D2
- bubblegum ชมพูบับเบิ้ล: #F7A8CB / #FFE3EF / #B3265F / #FFD66B / #A9C4FF
- mint มิ้นต์: #9ADDBF / #DFF5EA / #1E7A52 / #FFC9DE / #FFE27A
- sky ฟ้าน้ำนม: #9FBDF8 / #E4EDFF / #2D58B8 / #FFE27A / #F7A8CB
- peach ส้มพีช: #FFB48A / #FFE8DA / #B34A12 / #9FBDF8 / #FFE27A
- butter เหลืองเนย: #FFDB70 / #FFF3C9 / #8A6100 / #B7A6E3 / #9ADDBF

ตัวหนังสือหมึกบนพื้นพาสเทลทุกสีผ่าน contrast ≥ 4.5:1 ถ้าจะเพิ่มสีใหม่ต้องตรวจซ้ำ ใช้สี `deep` เฉพาะตัวหนังสือที่วางบนพื้นครีม/soft

## ค่าเริ่มต้นของแต่ละคน (ใกล้กับสีในปฏิทิน)

- Beiya 🔴 → doodle + bubblegum
- Beana 🟢 → flower + mint
- Bene 🟡 → blob + butter
- หน้ากลาง/หน้าผู้ปกครอง → flower + lavender

## ข้อห้าม

- ห้ามใช้ emoji เป็นไอคอนใน mockup ให้ใช้ SVG เส้นแทน (แอปจริงมี emoji อยู่บ้าง ถ้าผู้ใช้ไม่ว่าก็ใช้ต่อได้)
- ปุ่มต้องสูง ≥ 44px (ใช้บน iPad ทั้งด้วยนิ้วและ Apple Pencil)
